# Demo JS Banking API

This project is a small Node.js + Express demo that manages bank accounts (in-memory). It includes:
- REST API under `/api/accounts` (create, list, get, update, delete)
- Simple UI at `/` to create accounts
- Tests written with Vitest and Supertest
- Coverage reporting via `npm run coverage`

Quick commands:

```powershell
npm install
npm test
npm run coverage
npm start
```

Server runs on port `3000` by default. Open `http://localhost:3000` to use the UI.
